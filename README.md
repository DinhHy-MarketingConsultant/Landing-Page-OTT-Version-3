# Landing Page OTT Version 3

Phiên bản OTT theo hướng trình bày Symposium, nền sáng, màu cam và chân dung bất đối xứng. Mã nguồn HTML/CSS/JavaScript có thể chỉnh sửa trực tiếp.

- Xem web: https://dinhhy-marketingconsultant.github.io/Landing-Page-OTT-Version-3/
- Bàn giao: [HANDOVER.md](HANDOVER.md)
- Tải toàn bộ: chọn Code → Download ZIP trên GitHub.
- Chạy xem thử: tại thư mục này chạy `python3 -m http.server 8765`, mở http://localhost:8765/.

Form hiện chỉ lưu trên trình duyệt của người nhập, chưa gửi đến ban tổ chức.
